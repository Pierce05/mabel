- [ ] Run `app/index.html` locally and click through every page.
- [ ] Verify both Aesthetic and Chill modes on the dashboard and each dedicated page.
- [ ] Test Should I Buy This, Chai Pe Charcha, Financial Health, Badges & Aura, and Vision Board.
- [ ] Test vision-board drag, double-click-to-edit, sticker/font options, duplicate, delete, clear and reset.
- [ ] Test challenge rules and the daily aura surprise.
- [ ] Test on a real phone or responsive browser mode.
- [ ] Check all links and console errors.
- [ ] Decide whether to submit the product prototype URL or integrate `landing-last-step/index.html` as the root route.
- [ ] Deploy the `app/` folder as a static site (or move its contents to repository root).
- [ ] Put the public GitHub repository URL and live deployment URL into the FrontendArena form.
- [ ] Take screenshots of the dashboard, tracker, simulator, goals and mobile layout.
- [ ] Be transparent that authentication is prototype-only until a backend is added.

**Note:** `landing-last-step/index.html` is intentionally preserved separately, per your requested build order. Integrate it only after product QA.
